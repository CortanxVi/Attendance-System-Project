# Design System: KMUTNB Smart Attendance

## 1. Overview

**Creative North Star: "The Modern Academic Sandbox"**

ระบบการเช็คชื่อเข้าเรียนที่เน้นความทันสมัย น่าเชื่อถือ และเรียบง่าย โดยมีโครงสร้างที่สะอาดตาสไตล์มินิมอล ดีไซน์นี้สร้างขึ้นเพื่อสลัดภาพลักษณ์พอร์ทัลมหาวิทยาลัยแบบเดิมๆ ที่มีตัวอักษรหนาแน่นและสับสน มาสู่แอปพลิเคชันมือถือที่มีข้อมูลชัดเจน เข้าถึงได้รวดเร็ว และมีแอนิเมชันที่ตอบสนองอย่างเป็นธรรมชาติ (Responsive)

**Key Characteristics:**
- ให้ความสำคัญกับการจัดวางพื้นที่ว่าง (Negative Space) เพื่อลดภาระทางสมองของนักศึกษาขณะลงทะเบียนและเช็คชื่อ
- ใช้ไอคอน SVG ที่มีเส้นสายสะอาดตาและสม่ำเสมอ แทนการใช้ Emoji โดยเด็ดขาด
- สัญญาณสีแบบเจาะจงเฉพาะตัวเพื่อบ่งบอกสถานะการประมวลผล (เขียว/แดง) โดยใช้ตัวหนังสือหรือสัญลักษณ์กำกับร่วมด้วย

## 2. Colors

กลยุทธ์การใช้สีเน้นความประหยัดและจำกัดการแสดงผลเฉพาะส่วนสำคัญ เพื่อให้ความสำคัญกับเนื้อหาในบริบทวิชาการ

**The 10% Accent Rule.** ใช้สีเน้นแบรนด์ (เช่น สีแดงแสด/สีส้มทอง มจพ.) ไม่เกิน 10% ของพื้นผิวหน้าจอ เพื่อดึงดูดสายตาไปยังจุดสนใจหลักหรือปุ่มกดสำคัญเท่านั้น

- **Primary (สีหลัก)**: `[สีเน้นของแบรนด์ มจพ. จะถูกประเมินเมื่อเขียนโค้ดจริง]`
- **Neutral Background (พื้นหลังทั่วไป)**: `[จะถูกกำหนดสีในรหัสสีจริง เช่น สีขาวออฟไวท์หรือสีเทาอ่อนมาก]`
- **Success Ink (สีเช็คชื่อสำเร็จ)**: `[สีเขียวเข้มเพื่อให้อัตราส่วนคอนทราสต์ดีขึ้น]`
- **Failure Ink (สีเช็คชื่อล้มเหลว)**: `[สีแดงเข้มเพื่อความปลอดภัยและเตือนสติ]`

## 3. Typography

**Display Font:** Inter หรือ Outfit (sans-serif)
**Body Font:** Inter หรือ Outfit (sans-serif)
**Mono Font:** JetBrains Mono หรือ SF Mono (สำหรับการแสดงผลรหัสและเวกเตอร์)

**Character:** การจับคู่ฟอนต์แบบ Sans-Serif เดี่ยวที่มีความทันสมัย (Geometric Sans) เพื่อสร้างความคล่องตัวและทันสมัยแบบงานวิจัยทางวิทยาศาสตร์ อ่านได้เร็วบนอุปกรณ์พกพา

### Hierarchy
- **Display**: ฟอนต์หนาขนาดใหญ่สำหรับตัวเลขบอกเวลา หรือสถิติรวมในการเช็คชื่อ
- **Headline**: ฟอนต์หนาปานกลางสำหรับหัวข้อวิชาหรือหัวข้อหลักของหน้านั้นๆ
- **Title**: ฟอนต์ขนาดปกติ/กึ่งหนาสำหรับหัวข้อการ์ดรายวิชา
- **Body**: ฟอนต์ขนาดปกติสำหรับรายละเอียด (ความกว้างของข้อความไม่ควรเกิน 65–75 ตัวอักษรต่อบรรทัดเพื่อให้อ่านง่าย)
- **Label**: ฟอนต์ขนาดเล็กที่มีระยะห่างตัวอักษรเล็กน้อยสำหรับป้ายสถานะหรือรหัสนักศึกษา

## 4. Elevation

**The Flat-By-Default Rule.** อินเตอร์เฟสทั้งหมดใช้การแบ่งความลึกด้วยการซ้อนทับเลเยอร์สี (Tonal Layering) เป็นหลัก จะหลีกเลี่ยงการใช้เงาที่เข้มเกินไป เงาจะปรากฏเฉพาะเมื่อต้องการตอบสนองต่อการกระทำของผู้ใช้เท่านั้น (เช่น การกดปุ่มหรือการวางการ์ดซ้อนทับกัน)

## 6. Do's and Don'ts

### Do:
- **Do** ใช้ไอคอน SVG แบบมีสไตล์เส้นที่สม่ำเสมอแทนการใช้ Emoji
- **Do** รักษาระยะห่างช่องว่าง (Padding/Margin) อย่างสม่ำเสมอเพื่อให้หน้ารู้สึกโปร่งและสบายตา
- **Do** ตรวจสอบให้แน่ใจว่าตัวหนังสือสีขาวบนปุ่มสีเขียว/แดง มีอัตราส่วนคอนทราสต์ที่ผ่านเกณฑ์ WCAG AA (อย่างน้อย 4.5:1)

### Don't:
- **Don't** ใช้รูปเงาแบบกระจายหรือเอฟเฟกต์กระจกฝ้า (Glassmorphic) เป็นสไตล์เริ่มต้นเด็ดขาด
- **Don't** บีบอัดตัวหนังสือและข้อความต่างๆ ให้อยู่รวมกันอย่างหนาแน่นแบบระบบทะเบียนยุคเก่า
- **Don't** ตกแต่งหน้าด้วยสีสันเกินความจำเป็นนอกเหนือไปจากสีบอกสถานะและสีหลักของวิชาการ
