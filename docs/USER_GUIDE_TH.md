# คู่มือการใช้งานระบบบันทึกเวลาเข้าเรียน

คู่มือนี้ครอบคลุมการใช้งานสำหรับนักศึกษา อาจารย์ และผู้ดูแลระบบ หลังจากผู้ดูแลติดตั้งระบบและตั้งค่า Supabase Auth เรียบร้อยแล้ว

## 1. การเข้าสู่ระบบ

1. เปิด URL แบบ HTTPS ที่ผู้ดูแลระบบกำหนดด้วย browser รุ่นปัจจุบัน
2. เลือกเข้าสู่ระบบด้วยบัญชี Google ของสถาบัน
3. อนุญาตสิทธิ์กล้องเมื่อจะสแกน QR, ลงทะเบียนใบหน้า หรือเช็คชื่อด้วยใบหน้า
4. หากเข้าสู่ระบบสำเร็จแต่โหลดโปรไฟล์ไม่ได้ ให้กด **ลองใหม่** หนึ่งครั้ง หากยังไม่สำเร็จให้แจ้ง Request ID และเวลาที่เกิดปัญหาแก่ผู้ดูแล โดยไม่ส่ง access token หรือภาพบัตร

ระบบจะแสดงหน้าตามบทบาทของบัญชีโดยอัตโนมัติ Backend จะตรวจสิทธิ์ซ้ำทุกคำขอ ไม่ได้อาศัยเพียงการซ่อนเมนูในหน้าเว็บ

## 2. คู่มือสำหรับนักศึกษา

### 2.1 ตั้งค่าโปรไฟล์

1. เปิดแถบ **โปรไฟล์**
2. ตรวจชื่อ อีเมล รหัสนักศึกษา และรูปจาก Google Account
3. ตั้งชั้นปีได้ตั้งแต่ 1–8 แล้วบันทึก
4. ตรวจสถานะรายวิชา ใบหน้า และบัตร NFC จากรายการในหน้าโปรไฟล์

ถ้ายังไม่ได้ลงทะเบียน NFC ระบบจะแจ้งให้ดำเนินการกับอาจารย์ ผู้ใช้ไม่สามารถผูก UID ของบัตรเองได้

### 2.2 เข้าร่วมรายวิชา

1. เปิดแถบ **รายวิชา**
2. กรอกรหัสคลาสที่ได้รับจากอาจารย์
3. ตรวจชื่อวิชาและ Section ก่อนส่งคำขอ
4. รออาจารย์อนุมัติ หากส่งผิดสามารถยกเลิกคำขอที่ยังไม่ถูกพิจารณาได้

รหัสคลาสที่ถูกปิด หมดอายุ หรือถูกหมุนเปลี่ยนแล้วจะใช้ไม่ได้ การมีรหัสไม่ได้ทำให้เป็นสมาชิกทันทีจนกว่าอาจารย์อนุมัติ

### 2.3 ลงทะเบียนใบหน้า

ปุ่ม **ลงทะเบียนใบหน้า** จะแสดงเฉพาะบัญชีที่ยังไม่เคยลงทะเบียน

1. เตรียมบัตรนักศึกษาและอยู่ในบริเวณที่แสงสม่ำเสมอ
2. ถ่ายหรือเลือกภาพบัตรที่อ่านรหัสได้ชัด ระบบจะย่อภาพและส่งไปยัง Light OCR ผ่าน Backend
3. รหัสบนบัตรต้องตรงกับบัญชีที่เข้าสู่ระบบ
4. รอข้อความว่าโมเดลตรวจจับใบหน้าพร้อมแล้ว
5. วางใบหน้าเพียงหนึ่งคนในกรอบ เคลื่อนเข้าใกล้ตามคำแนะนำ แล้วกลับเข้ากรอบ
6. กระพริบตาตาม challenge ที่ระบบกำหนด อย่าหันหน้าหลบกล้อง
7. รอผลจาก Backend จนเสร็จ ห้ามปิดหน้าหรือสลับแอประหว่างอัปโหลด

ระบบส่งเฉพาะภาพหลักฐานที่เลือก ไม่ส่งวิดีโอทั้งชุดและไม่เก็บภาพเช็คชื่อถาวร หากลงทะเบียนแล้วและต้องแก้ไขข้อมูล ให้ติดต่อผู้ดูแลระบบถาวร

### 2.4 เช็คชื่อด้วย Dynamic QR และใบหน้า

1. อาจารย์ต้องเปิดคาบและแสดง Dynamic QR บนอีกหน้าจอ
2. เปิดหน้าหลักของนักศึกษา แล้วสแกน QR ปัจจุบัน
3. หลัง QR ผ่าน ให้ถ่ายบัตรและทำ Liveness ตามหน้าจอ
4. รอข้อความยืนยันชื่อ วิธีเช็คชื่อ เวลา และสถานะมาเรียน/สาย/ขาด

QR บนจออาจารย์เปลี่ยนทุก 10–15 วินาที ส่วน challenge หลังสแกนสำเร็จใช้ได้ตามเวลาที่ Backend แสดงและใช้เช็คชื่อได้ครั้งเดียว ภาพ QR เก่า ภาพนิ่งใบหน้า และวิดีโอ replay ต้องไม่ผ่านระบบ

### 2.5 เช็คชื่อด้วย NFC

1. ใช้บัตรที่อาจารย์หรือผู้ดูแลผูกกับบัญชีไว้แล้ว
2. แตะบัตรกับเครื่องอ่านของคาบที่เปิดอยู่
3. ตรวจว่ารายชื่อแสดงขึ้นที่หน้าอาจารย์ทันที

หากบัตรสูญหาย ให้แจ้งผู้ดูแลยกเลิก UID เดิมก่อนผูกบัตรใหม่ บัตรแบบ UID-only สามารถถูกโคลนได้ จึงควรใช้ร่วมกับการควบคุมสถานที่และการตรวจรายชื่อ

### 2.6 ประวัติและคำร้อง

- แถบ **ประวัติ** แสดงข้อมูลการเข้าเรียนของบัญชีปัจจุบัน
- แถบ **คำร้อง** ใช้ส่งข้อความ รูปภาพ และเอกสารให้อาจารย์ของรายวิชาที่เกี่ยวข้อง
- ตรวจ preview ก่อนส่งและหลีกเลี่ยงเอกสารที่มีข้อมูลเกินความจำเป็น
- ระบบจำกัดชนิด ขนาด และจำนวนไฟล์ หาก preview ไม่ได้ให้ดาวน์โหลดเฉพาะไฟล์ที่เชื่อถือได้

## 3. คู่มือสำหรับอาจารย์

### 3.1 สร้างและจัดการรายวิชา

1. เปิด **รายวิชาที่สอน** แล้วสร้างรายวิชา
2. ระบุรหัสวิชา ชื่อ Section ภาคเรียน และปีการศึกษา
3. กด **จัดการรายวิชา** เพื่อเปิดศูนย์จัดการ
4. ใช้แถบข้อมูลรายวิชา เกณฑ์เข้าเรียน สมาชิก รหัสคลาส ประวัติ และพื้นที่อันตราย

ตั้งเกณฑ์มาสาย ขาดเรียน จำนวนคาบ และเปอร์เซ็นต์ขาดสูงสุดก่อนเปิดคาบแรก

### 3.2 รหัสคลาสและสมาชิก

- เปิด/ปิดรหัสคลาส กำหนดวันหมดอายุ หรือหมุนรหัสใหม่จากแถบ **รหัสคลาส**
- การหมุนรหัสทำให้รหัสเดิมใช้ไม่ได้ทันที
- ตรวจชื่อ รหัส ชั้นปี และ Section ก่อนอนุมัติคำขอ
- นำเข้ารายชื่อด้วย `.xlsx` หรือ `.csv` ผ่าน Preview → ตรวจผล → Commit
- แก้แถวผิดรูปแบบหรือข้อมูลซ้ำก่อน Commit และไม่ใช้ข้อมูลจริงทดสอบใน Staging

### 3.3 เปิดคาบและ Dynamic QR

1. เลือกรายวิชาและเปิดคาบเรียน
2. แสดง QR บนจอที่นักศึกษาเห็นได้ในห้อง
3. เฝ้ารายชื่อแบบทันที นักศึกษาที่เช็คชื่อด้วยใบหน้าหรือ NFC สำเร็จจะปรากฏพร้อมวิธีและเวลา
4. ปิดคาบเมื่อหมดเวลา

ห้ามแชร์ URL หรือ token ภายในของ session และไม่ควรเปิดคาบทิ้งไว้หลังสิ้นสุดการเรียน

### 3.4 สถานะ รายงาน และคำร้อง

- เปิด **ประวัติเข้าเรียน** เพื่อตรวจรายคาบและแก้สถานะเมื่อมีหลักฐาน
- ใช้หน้ารายงานส่งออกข้อมูลและเก็บไฟล์ในพื้นที่ควบคุมสิทธิ์
- เปิด **ตั้งค่าระบบ → คำร้องของนักศึกษา** เพื่อตอบข้อความ ตรวจ preview และเปลี่ยนสถานะคำร้อง

### 3.5 ขอสิทธิ์ผู้ดูแลชั่วคราว

1. เปิด **ตั้งค่าระบบ → สิทธิ์ผู้ดูแลชั่วคราว**
2. ระบุเหตุผลแล้วส่งคำขอ
3. ผู้ดูแลถาวรอีกคนต้องอนุมัติครั้งแรก
4. ตั้งและยืนยัน PIN ตัวเลข 6 หลักภายในเวลาที่กำหนด
5. ครั้งต่อไปกรอก PIN เพื่อเปิดสิทธิ์ตามเวลาชั่วคราว
6. ออกจากโหมดผู้ดูแลเมื่อทำงานเสร็จ

หลีกเลี่ยงเลขเรียง เลขซ้ำ วันเกิด หรือ PIN ที่ใช้กับระบบอื่น ระบบล็อกชั่วคราวเมื่อกรอกผิดเกินกำหนด และสิทธิ์ชั่วคราวไม่อนุญาตให้เปลี่ยน face embedding

## 4. คู่มือสำหรับผู้ดูแลระบบถาวร

- **ภาพรวมระบบ:** ตรวจจำนวนผู้ใช้ รายวิชา และสถานะสำคัญ
- **จัดการผู้ใช้:** สร้าง ตรวจ และแก้ข้อมูล/บทบาทด้วยหลัก least privilege
- **จัดการรายวิชา:** ตรวจรายวิชาทั้งระบบและลบเมื่อสำรองหรือส่งออกรายงานแล้ว
- **จัดการการลงทะเบียน:** ลงทะเบียนใบหน้าแบบมีผู้ดูแลอยู่ต่อหน้าและผูก NFC หลังยืนยันตัวตน
- **Audit Log:** ตรวจเหตุการณ์สำคัญโดยไม่คัดลอก token หรือข้อมูลชีวมิติออกนอกระบบ
- **รายงาน:** ส่งออกตามวัตถุประสงค์และ retention policy
- **สิทธิ์ชั่วคราว:** ตรวจผู้ร้องขอ เหตุผล ขอบเขต และเวลา สามารถ revoke enrollment เมื่อบุคลากรเปลี่ยนหน้าที่หรือสงสัยว่า PIN รั่ว

## 5. การออกจากระบบและความปลอดภัย

1. ออกจากระบบเมื่อใช้เครื่องร่วมกัน
2. ไม่บันทึก PIN, token หรือ service key ในพื้นที่ที่บุคคลอื่นเข้าถึงได้
3. ไม่ส่งภาพใบหน้า บัตร รายชื่อ หรือ log ที่มีข้อมูลส่วนบุคคลผ่านช่องทางสาธารณะ
4. เมื่อรายงานปัญหา ให้ส่งเวลา หน้าที่เกิดปัญหา HTTP status และ Request ID เท่านั้น
5. ผู้ดูแลต้องปิดบัญชีหรือ revoke session เมื่อบัญชีบุคลากรถูกยกเลิก

## 6. ปัญหาที่พบบ่อย

| อาการ | วิธีตรวจสอบ |
|---|---|
| กล้องไม่เปิด | ตรวจว่า URL เป็น HTTPS, อนุญาต Camera permission และกล้องไม่ถูกแอปอื่นใช้อยู่ |
| โหลดโมเดลนาน | รีเฟรชหนึ่งครั้ง ตรวจเครือข่ายและไฟล์ `/models`/`/mediapipe`; ไม่ควรเริ่ม QR จนโมเดลพร้อม |
| OCR ไม่พบรหัส | ถ่ายบัตรตรง ไม่สะท้อนแสง ไม่เบลอ และให้รหัสอยู่ในภาพครบ |
| Liveness ไม่ผ่าน | อยู่ในแสงสม่ำเสมอ วางเพียงหนึ่งใบหน้า เข้า–กลับกรอบ และกระพริบตาชัดโดยไม่หันหน้า |
| QR หมดอายุ | สแกน QR ปัจจุบันจากจออาจารย์ใหม่ |
| เข้าร่วมรายวิชาไม่ได้ | ตรวจรหัสคลาส สถานะเปิด วันหมดอายุ และรออาจารย์อนุมัติ |
| `/auth/me` ตอบ 401 | session หมดอายุ ให้ออกจากระบบแล้วเข้าสู่ระบบใหม่ |
| `/auth/me` หรือ readiness ตอบ 503 | แจ้งผู้ดูแลตรวจ Backend, Supabase และ Light OCR พร้อม Request ID |
